# 🧮 Algorithm Study Repository

알고리즘 학습과 코딩테스트 대비를 위한 개인 학습 저장소입니다.

## 📁 프로젝트 구조

### 📚 공부/

알고리즘 이론 학습 및 구현 연습 (플랫폼별 정리)

#### 🔥 Programmers

- **BFSDFS**: 너비우선탐색, 깊이우선탐색 관련 문제
- **Hash**: 해시 자료구조 활용 문제
- **검색과정렬**: 탐색 및 정렬 알고리즘
- **그리디**: 그리디 알고리즘 문제
- **재귀(Recursion)**: 재귀 함수 활용 문제
- **집합(Set)**: 집합 자료구조 활용
- **팰린드롬**: 팰린드롬 관련 문제
- **단순구현**: 기본적인 구현 문제
- **누워서읽는알고리즘**: 알고리즘 이론 정리

#### 📖 Inflearn 강의

- **Section 1**: 기본 문제 (홀수, 최솟값, 삼각형 판별 등)
- **Section 2**: 1차원 배열 탐색
- **Section 3**: 문자열 탐색
- **Section 4**: 완전탐색
- **Section 5**: 효율성 (투포인터, 슬라이딩윈도우, 해시)
- **Section 6**: 자료구조 (스택, 큐)
- **Section 7**: 정렬과 탐색 (이분검색)
- **Section 8**: 재귀함수와 완전탐색 (DFS)
- **Section 9**: 그래프와 탐색 (DFS, BFS)
- **Section 10**: 동적계획법
